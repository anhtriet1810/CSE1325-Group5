## Project Titles

- Room Supply Distribution System
- Equipment Storage System

## Project Overview

### What type of software will your team develop?

We will develop a map-like software that allows you to add and remove rooms and specify what supplies go to which room.

### What will the software generally allow users to do?

The software will let a user organize how supplies are distributed and stored throughout a building. And also make a map for how the building looks like.

### What is the overall purpose of the application?

The purpose of the application is to make it easier to document where supplies go. And to allow someone to request supplies to bring to their room.

## Problem Being Addressed

Sometimes you are in a room with sufficient space, but not enough supplies for everyone in the room. This software is supposed to help with that by allowing you to create a map of rooms in a building that you can then specify what supplies will go to each room.

## Intended Users

People who manage inventory and want to create a map of their building to determine where supplies go.

## Why We Picked This Topic

We wanted to make something that helps us keep track of items in a building and it is something that we can improve over time. The software can be useful because knowing where things are and how many are at that location is helpful so that we don’t go there only to be disappointed and find that what we are looking for is not there.
